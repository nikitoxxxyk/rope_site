# [Kapron.by](https://kapron.by/) — Сайт по продаже веревочной продукции

Это коммерческий проект созданный для компании по производству и продаже веревок, канатов и шнуров kapron. Сайт разработан на Django и включает каталог товаров, фильтрацию, корзину-прайслист, формы обратной связи и интеграцию с почтой.

## 🚀 Функционал

- **Каталог товаров** с фильтрацией по категориям, цене и диаметру.
- **Корзина-прайслист** — сбор заказа без онлайн-оплаты.
- **Оформление заказа** — отправка заявки менеджеру gj email.
- **Форма обратной связи** и **заказ звонка**.
- **Админ-панель** с кастомными настройками (Unfold).
- **Адаптивный дизайн** на Bootstrap.
- **Docker-сборка** для развертывания проекта.

## 🛠️ Технологии

- **Backend:** Django 5.2, Python 3.10+
- **База данных:** SQLite для разработки / MySQL для продакшена
- **Фронтенд:** Bootstrap 5, HTML/CSS, JavaScript
- **Дополнительно:** Whitenoise, PyMySQL, python-decouple
- **Контейнеризация:** Docker, Docker Compose
